# 36 - 用户画像

> 本文档帮助理解"村务连心桥"的真实用户，指导产品决策和适老化设计。

## 36.1 用户角色分类

### 36.1.1 普通村民（核心用户，占 80%）
- 年龄段：35-75 岁，中老年为主
- 文化程度：小学至初中为主，部分高中
- 智能机使用习惯：会基础微信操作（看朋友圈、发语音），不熟悉复杂表单
- 视力/听力：部分老花眼、听力下降
- 主要诉求：反映家门口的事、看村务动态、查惠农价格、找村委电话

### 36.1.2 村委班子（次要用户，占 15%）
- 年龄段：30-60 岁
- 文化程度：高中至大专
- 智能机使用习惯：熟练，会使用各类小程序
- 主要诉求：处理工单、发布通知、记录会议、对上汇报

### 36.1.3 书记/管理员（核心管理者，占 5%）
- 年龄段：35-55 岁
- 文化程度：大专至本科
- 智能机使用习惯：非常熟练，每日高频使用
- 主要诉求：审核认证、亲阅件处理、信箱回信、考核看板、对上汇报

### 36.1.4 留守老人（特殊群体）
- 年龄段：65-90 岁
- 文化程度：小学或文盲
- 智能机使用习惯：仅会接打电话，子女帮助安装小程序
- 主要诉求：每日签到报平安、紧急求助一键触发

## 36.2 用户场景

### 场景 A：王大爷反映家门口垃圾乱堆
- 触发：出门发现门口垃圾
- 操作：打开小程序 → 首页"随手拍" → 拍照 → 选类型"垃圾乱堆" → 语音说"门口堆了 3 天没人清" → 提交
- 期望：1 小时内村委派人处理，第二天看到公示墙更新

### 场景 B：李阿姨查询惠农价格
- 触发：要去集市卖水稻
- 操作：打开小程序 → 首页"惠农价格" → 看到水稻最新价
- 期望：价格准、更新及时

### 场景 C：张书记处理工单
- 触发：收到派单通知
- 操作：消息中心 → 工单详情 → 处理 → 拍处理结果照片 → 标记完成
- 期望：操作流畅，不卡顿

### 场景 D：留守老人刘奶奶每日签到
- 触发：早上起床
- 操作：打开小程序 → 每日签到 → 选"正常"
- 期望：3 步内完成，无需输入文字

### 场景 E：村主任发布广播
- 触发：突发紧急通知
- 操作：mine → 发布广播 → 输入内容 → 标记"紧急"
- 期望：全村立刻收到通知

## 36.3 用户痛点与解决方案

| 痛点 | 影响人群 | 当前解决 | v1.5 计划 |
|------|---------|---------|----------|
| 看不清字 | 老年村民 | 字号 ≥32rpx | 大字号切换 |
| 不会打字 | 老年村民 | VoiceInput 接入 6 表单 | 接入更多表单 |
| 不知道工单进度 | 提交反映的村民 | 列表显示状态 | ProgressTimeline 时间轴 |
| 派单后没人管 | 责任人 | 自动派单+通知 | my-dispatched 入口已建 |
| 通知收不到 | 全体 | 订阅消息 | 短信兜底（v2.0） |
| 网络差一直转圈 | 全体 | 超时+错误态 | 骨架屏 |
| 表单填一半被打断 | 全体 | 草稿自动保存 | 已完成 |
| 工单超时无人管 | 全体 | sendOverdueReminder 定时器 | 升级通知已加 |

## 36.4 调研建议

部署后 1 个月内：
1. 随机抽样 20 户村民入户访谈
2. 收集年龄段、智能机型号、网络环境、使用频率
3. 收集"最常用的 3 个功能"和"最不会用的 3 个功能"
4. 根据调研结果调整 docs/29 二次开发指南
