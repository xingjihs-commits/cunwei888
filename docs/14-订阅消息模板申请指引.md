# 第十四部分：订阅消息模板申请指引

**适用对象**：村文书、技术对接人
**前置条件**：小程序已注册，AppID已获取

---

## 14.1 申请入口

### 14.1.1 登录微信公众平台

1. 浏览器打开 https://mp.weixin.qq.com
2. 使用小程序管理员微信扫码登录
3. 确认登录的是「村务连心桥」小程序后台

### 14.1.2 进入订阅消息

1. 左侧菜单点击「功能」→「订阅消息」
2. 显示两个Tab：
   - **公共模板库**：微信提供的标准模板，直接选用
   - **我的模板**：已申请的模板列表

### 14.1.3 公共模板库 vs 自定义模板

| 类型 | 适用场景 | 审核时间 | 限制 |
|------|---------|---------|------|
| 公共模板库 | 标准场景（如订单、预约、审核结果） | 即时可用 | 关键词固定，不能修改 |
| 自定义模板 | 个性化场景 | 3-7个工作日 | 需提供使用说明 |

**本平台建议**：5个模板全部从公共模板库选用。

### 14.1.4 一次性订阅 vs 长期订阅

| 类型 | 触发条件 | 有效期 | 适用场景 |
|------|---------|--------|---------|
| 一次性订阅 | 用户每次操作时授权 | 仅发送1次 | 工单状态更新、价格提醒 |
| 长期订阅 | 一次授权，长期发送 | 长期有效 | 紧急广播、超时催办 |

**政务民生类长期订阅申请条件**：
- 小程序服务类目必须选「政务民生」
- 需提供政府资质证明（村委会可凭统一社会信用代码证书）
- 审核时间约7-15个工作日

## 14.2 所有订阅消息模板的申请详情

本平台代码中使用5个订阅消息模板（见`cloudfunctions/sendSubscribeMessage/index.js`的`TEMPLATES`对象）：

### 14.2.1 模板1：新工单通知（变量名`new_feedback`，占位符`tmpl_feedback_notify`）

| 项目 | 内容 |
|------|------|
| **模板名称** | 新工单提醒（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **关键词选择** | thing1（事项名称）、time2（提交时间）、thing3（处理提示） |
| **申请文案示例** | 本模板用于村民提交反映工单后，通知村委管理员及时处理。村民通过小程序提交反映，村委需第一时间知晓并派单处理。 |
| **审核被拒常见原因** | 关键词选择不符合标准词库；申请说明过于简单 |
| **应对方法** | 改选公共词库中的标准关键词；补充详细使用场景 |
| **是否需要长期订阅** | 否（一次性订阅即可） |

### 14.2.2 模板2：工单状态更新（变量名`status_update`，占位符`tmpl_status_update`）

| 项目 | 内容 |
|------|------|
| **模板名称** | 工单状态变更通知（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **关键词选择** | thing1（工单名称）、phrase2（新状态）、time3（更新时间） |
| **申请文案示例** | 本模板用于工单状态变更时，通知提交工单的村民。村民提交反映后，村委处理工单时，村民需及时了解处理进度。 |
| **审核被拒常见原因** | 关键词不匹配；申请说明未说明用户授权场景 |
| **应对方法** | 从词库选标准关键词；明确说明"用户提交工单时授权" |
| **是否需要长期订阅** | 否（一次性订阅，用户提交工单时授权） |

### 14.2.3 模板3：任务派发（变量名`new_task`，占位符`tmpl_task_assign`）

| 项目 | 内容 |
|------|------|
| **模板名称** | 任务分配通知（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **关键词选择** | thing1（任务名称）、time2（派发时间）、thing3（办理要求） |
| **申请文案示例** | 本模板用于村委向责任人派发政策落实任务时，通知责任人及时办理。如耕地补贴申报、医保缴费等任务。 |
| **审核被拒常见原因** | 关键词选择不当 |
| **应对方法** | 选thing+time标准词 |
| **是否需要长期订阅** | 否 |

### 14.2.4 模板4：价格更新（变量名`price_update`，占位符`tmpl_price_alert`）

| 项目 | 内容 |
|------|------|
| **模板名称** | 价格变动提醒（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **关键词选择** | thing1（农产品名称）、amount2（新价格）、time3（更新时间） |
| **申请文案示例** | 本模板用于惠农价格更新时，通知已订阅该品种的村民。村民关注某农产品价格，价格变动时及时知晓。 |
| **审核被拒常见原因** | 关键词amount不符合标准格式 |
| **应对方法** | 改用number或character_data类型关键词 |
| **是否需要长期订阅** | 否（用户订阅时授权，每次价格变动触发） |

### 14.2.5 模板5：超时催办（变量名`overdue_reminder`，占位符`tmpl_overdue_reminder`）

| 项目 | 内容 |
|------|------|
| **模板名称** | 超时催办提醒（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **关键词选择** | thing1（工单名称）、time2（超时时间）、thing3（处理要求） |
| **申请文案示例** | 本模板用于工单超时未处理时，自动通知责任人及时处理。由系统定时触发器每天8点检查并发送。 |
| **审核被拒常见原因** | 关键词不符合；说明未提及定时触发 |
| **应对方法** | 明确说明"系统自动触发"；选标准关键词 |
| **是否需要长期订阅** | **是（建议申请长期订阅）**，因系统自动触发，无法每次获取用户授权 |

## 14.3 模板ID配置

### 14.3.1 模板ID查看位置

1. 登录微信公众平台
2. 「功能」→「订阅消息」→「我的模板」
3. 每个模板显示「模板ID」（类似`aBcDeFgHiJkLmNoPqRsT`）
4. 复制模板ID

### 14.3.2 模板ID填入代码位置

**文件**：`cloudfunctions/sendSubscribeMessage/index.js`
**位置**：文件顶部的`TEMPLATES`对象

当前代码（占位符）：
```javascript
const TEMPLATES = {
  new_feedback: 'tmpl_feedback_notify',     // 替换为真实模板ID
  status_update: 'tmpl_status_update',       // 替换为真实模板ID
  new_task: 'tmpl_task_assign',              // 替换为真实模板ID
  price_update: 'tmpl_price_alert',          // 替换为真实模板ID
  overdue_reminder: 'tmpl_overdue_reminder'  // 替换为真实模板ID
}
```

替换后示例：
```javascript
const TEMPLATES = {
```

替换后需重新部署sendSubscribeMessage云函数。

### 14.3.3 环境变量配置方法（可选）

如不想把模板ID写在代码里，可用环境变量：

1. 云开发控制台→云函数→sendSubscribeMessage→环境变量
2. 添加变量：`TEMPLATE_FEEDBACK`、`TEMPLATE_STATUS`等
3. 代码改为：`process.env.TEMPLATE_FEEDBACK`

### 14.3.4 测试模板消息发送

1. 部署sendSubscribeMessage云函数
2. 云开发控制台→云函数→sendSubscribeMessage→测试
3. 输入测试参数：
```json
{
  "type": "new_feedback",
  "recordId": "test_001",
  "title": "测试工单"
}
```
4. 点击「运行」
5. 检查管理员微信是否收到订阅消息

### 14.3.5 常见发送失败原因

| 失败原因 | 错误码 | 解决方法 |
|---------|--------|---------|
| 用户未授权 | 43101 | 引导用户授权订阅 |
| 模板ID错误 | 40037 | 检查模板ID是否正确 |
| 参数格式错误 | 47003 | 检查关键词类型是否匹配 |
| 用户接收频率超限 | -1 | 控制发送频率，每日≤3条 |
| 模板已下架 | 42043 | 重新申请模板 |

## 14.4 订阅授权引导

### 14.4.1 村民首次提交工单时弹出订阅

**代码位置**：`pages/feedback/feedback.vue`的`onSubmit`函数

**当前实现**：提交工单后调用submitFeedback云函数，云函数内部调用sendSubscribeMessage。

**建议增强**：在提交前先调用`uni.requestSubscribeMessage`引导授权：

```javascript
// 在onSubmit函数开头添加：
// #ifdef MP-WEIXIN
const subscribeRes = await new Promise((resolve) => {
  wx.requestSubscribeMessage({
    tmplIds: ['tmpl_status_update'],  // 替换为真实模板ID
    success(res) { resolve(res) },
    fail() { resolve({}) }
  })
})
// #endif
```

### 14.4.2 uni.requestSubscribeMessage调用方式

```javascript
wx.requestSubscribeMessage({
  tmplIds: ['模板ID1', '模板ID2'],
  success(res) {
    // res[模板ID]的值：'accept'（同意）/ 'reject'（拒绝）/ 'ban'（被禁用）
    if (res['模板ID1'] === 'accept') {
      console.log('用户同意订阅')
    }
  },
  fail(err) {
    console.error('订阅授权失败', err)
  }
})
```

### 14.4.3 村民拒绝授权后引导手动开启

```javascript
// 检测到用户拒绝授权后，引导开启
if (res['模板ID'] === 'reject' || res['模板ID'] === 'ban') {
  uni.showModal({
    title: '开启通知',
    content: '为了及时收到工单处理通知，请在设置中开启订阅消息',
    confirmText: '去设置',
    success(modalRes) {
      if (modalRes.confirm) {
        // #ifdef MP-WEIXIN
        wx.openSetting({
          success(settingRes) {
            console.log('设置结果', settingRes)
          }
        })
        // #endif
      }
    }
  })
}
```

### 14.4.4 长期订阅 vs 一次性订阅

| 类型 | 授权方式 | 适用模板 |
|------|---------|---------|
| 一次性 | 每次提交工单时授权 | status_update、price_update |
| 长期 | 一次授权长期有效 | overdue_reminder、new_feedback（管理员） |

### 14.4.5 提高村民授权率的技巧

1. **场景化引导**：在用户提交工单时弹窗，说明"开启通知可及时了解处理进度"
2. **按钮文案设计**：用"开启通知"代替"订阅消息"
3. **首页引导**：首页放置"开启通知"按钮，引导用户一次性授权所有模板
4. **村干部上门教学**：网格员入户时帮老人开启

## 14.5 订阅授权率提升方案

### 14.5.1 首页放置"开启通知"引导按钮

在`pages/index/index.vue`首页顶部栏增加"开启通知"按钮：

```html
<view class="notify-btn" @click="subscribeAll">
  <text>🔔 开启通知</text>
</view>
```

```javascript
async function subscribeAll() {
  // #ifdef MP-WEIXIN
  wx.requestSubscribeMessage({
    tmplIds: [
      'tmpl_status_update',
      'tmpl_price_alert',
      'tmpl_overdue_reminder'
    ],
    success(res) {
      uni.showToast({ title: '通知已开启', icon: 'success' })
    }
  })
  // #endif
}
```

### 14.5.2 提交成功后弹窗引导订阅

在`submitFeedback`成功后：

```javascript
if (res.success) {
  uni.showModal({
    title: '提交成功',
    content: '是否开启通知，及时了解处理进度？',
    confirmText: '开启',
    success(modalRes) {
      if (modalRes.confirm) {
        // 调用requestSubscribeMessage
      }
    }
  })
}
```

### 14.5.3 个人中心设置"消息通知"入口

在`pages/mine/mine.vue`增加"消息通知设置"菜单项。

### 14.5.4 村干部上门教学时帮村民开启

网格员入户推广时：
1. 打开村民手机微信
2. 进入小程序
3. 点击"开启通知"
4. 在弹窗中点"允许"
5. 完成所有模板授权

**预期效果**：通过以上4种方式，授权率可达70%+。
