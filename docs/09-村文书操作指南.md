# 村务连心桥村文书操作指南

**适用对象**：村文书、村委委员、信息发布员
**写作原则**：语言通俗、步骤清晰、每步不超过3行
**生效日期**：2026年1月1日

---

## 一、如何发布村务新闻

### 1.1 进入发布页

1. 打开小程序「我的」页面
2. 找到「管理员功能」→「内容发布」
3. 点击进入，选择顶部「村务新闻」Tab

### 1.2 填写内容

1. 标题：写清什么事，15字以内
2. 分类：选「村务」「党建」「通知」「活动」之一
3. 内容：详细描述，可分段，最多2000字

### 1.3 上传图片

**拍照要求**：
- 横版拍摄（手机横着拿）
- 光线充足（白天室外最佳）
- 有人物有场景（不能只拍空景）
- 至少3张（全景1张、近景1张、人物1张）

**上传步骤**：
1. 点击「添加图片」
2. 选「拍照」或「相册」
3. 最多9张，建议5-6张
4. 长按可删除

### 1.4 发布

1. 检查内容无误
2. 点「发布」按钮
3. 显示「发布成功」即完成
4. 自动同步到首页新闻流

---

## 二、如何发布信息公示

### 2.1 进入发布页

1. 「我的」→「内容发布」→「信息公示」

### 2.2 填写内容

1. 标题：写明公示类别+事项，如「2026年Q1财务公示」
2. 分类：党务/村务/财务/惠农/应急（5选1）
3. 责任人：填写负责人姓名
4. 内容：详细公示内容

### 2.3 财务公示特殊要求

财务类公示必须勾选：
- ☑ 经村务监督委员会审核

未经监委审核的财务公示不能发布。

### 2.4 发布

1. 检查分类是否正确
2. 点「发布」
3. 财务类自动显示金色标识

---

## 三、如何更新惠农价格

### 3.1 进入发布页

1. 「我的」→「内容发布」→「惠农价格」

### 3.2 填写价格

1. 农产品名称：如「水稻」「玉米」
2. 价格：数字，如2.5
3. 单位：如「元/斤」
4. 市场：如「村集市」
5. 趋势：涨/跌/平
6. 备注：可选，如「近期上涨，建议观望」

### 3.3 发布

1. 点「发布」
2. 旧价格自动标记为过期
3. 已订阅村民收到通知

---

## 四、如何发布政策落实任务

### 4.1 进入发布页

1. 「我的」→「内容发布」→「政策任务」

### 4.2 填写任务

1. 标题：写明任务内容
2. 内容：详细要求
3. 责任人：选承办人
4. 截止时间：选日期
5. 紧急程度：一般/紧急/特急

### 4.3 发布

1. 检查截止时间是否合理
2. 点「发布」
3. 责任人自动收到订阅消息

---

## 五、如何处理工单

### 5.1 查看工单

1. 「我的」→「工单管理」
2. 按「待处理」「处理中」「已完成」筛选

### 5.2 派单

1. 点工单进入详情
2. 选状态：「已派单」
3. 填承办人姓名+职务
4. 点「提交处理」

### 5.3 处理完成

1. 选状态：「已完成」
2. 填写处理结果（详细描述）
3. 上传处理照片（至少1张）
4. 点「提交处理」
5. 村民自动收到通知

### 5.4 驳回

1. 选状态：「已驳回」
2. 填写驳回原因
3. 点「提交处理」

---

## 六、如何回复书记信箱

### 6.1 查看信件

1. 书记本人登录小程序
2. 「我的」→「管理员功能」
3. 找到「书记信箱」入口
4. 查看所有来信

### 6.2 回复

1. 点信件进入详情
2. 阅读：点「已阅」标记状态
3. 回复：在回复框填写内容
4. 选择是否公开（公开则其他村民可见书记回复）
5. 点「回复」按钮

### 6.3 注意事项

- 紧急信件2小时内回复
- 一般信件2个工作日内回复
- 匿名信件无法直接联系，回复内容需通用
- 敏感问题慎重回复，必要时上报上级

---

## 七、如何发布广播

### 7.1 进入发布

1. 书记本人登录
2. 「我的」→「管理员功能」→「发布广播」

### 7.2 填写内容

1. 标题：简洁有力
2. 内容：详细通知内容
3. 紧急程度：勾选「紧急」则全村优先收到

### 7.3 发布

1. 检查内容
2. 点「发布」
3. 所有认证村民自动收到消息通知

---

## 八、常见问题处理

### 8.1 小程序打不开

| 现象 | 处理方法 |
|------|---------|
| 加载慢 | 关闭重开，或重启微信 |
| 白屏 | 清除缓存：「我的」→「个人信息」→「清除缓存」 |
| 提示网络错误 | 检查手机网络，或切换WiFi/4G |

### 8.2 云函数报错

| 现象 | 处理方法 |
|------|---------|
| 提交工单失败 | 检查是否已实名认证 |
| 上传图片失败 | 图片可能过大，建议压缩后重传 |
| 数据不显示 | 下拉刷新，或联系村文书检查云函数 |

### 8.3 订阅消息收不到

| 现象 | 处理方法 |
|------|---------|
| 没收到通知 | 检查微信「订阅消息」设置，是否允许通知 |
| 通知太频繁 | 可单独取消某类订阅 |
| 老人不会操作 | 子女代为设置，或上门指导 |

### 8.4 用户认证问题

| 现象 | 处理方法 |
|------|---------|
| 认证不通过 | 检查身份证号、手机号是否正确 |
| 提示已认证 | 该openid已绑定其他账号，联系村文书处理 |
| 认证审核慢 | 24小时内审核，超时联系村文书 |

### 8.5 内容发布问题

| 现象 | 处理方法 |
|------|---------|
| 提示违规 | 修改敏感内容后重新发布 |
| 图片上传失败 | 单张不超过5MB，建议压缩到1MB |
| 发布后看不到 | 等待1-2分钟刷新，或联系村文书 |

## 九、操作小贴士

### 9.1 提高效率的技巧

1. **批量操作**：周一集中处理一周工单
2. **模板复用**：常用文案保存为模板
3. **语音输入**：长文用语音输入更快
4. **图片压缩**：发布前先压缩，加快上传
5. **定时发布**：重要内容固定时间发布

### 9.2 避免常见错误

1. ❌ 不要发布未审核的财务公示
2. ❌ 不要删除已公示的工单记录
3. ❌ 不要在广播中发布个人观点
4. ❌ 不要让多人共用管理员账号
5. ❌ 不要忘记每月1日数据备份

## 十、值班要求

### 10.1 工作日值班

- 工作日8:30-17:00村委办公室值班
- 接听村委值班电话
- 处理当日工单（4小时内派单）

### 10.2 周末/节假日值班

- 每天2次检查小程序（上午9点+下午3点）
- 紧急工单即时处理
- 紧急广播由值班村支书发布

### 10.3 紧急情况处置

| 紧急情况 | 处置流程 |
|---------|---------|
| 火灾/急病/治安 | 立即拨打110/120/119 |
| 自然灾害 | 上报街道办+发布紧急广播 |
| 重大舆情 | 立即上报村支书+街道办 |
| 系统故障 | 排查+通知村民+上报街道办 |
