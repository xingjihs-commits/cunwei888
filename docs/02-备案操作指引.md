## 二、微信公众平台备案填写步骤

### 2.1 第一步：登录微信公众平台

1. 浏览器打开 https://mp.weixin.qq.com
2. 使用小程序管理员微信扫码登录
3. 进入小程序管理后台

**截图说明**：登录后页面左上角显示小程序名称，确认是您要备案的小程序

### 2.2 第二步：进入备案入口

1. 左侧菜单点击「设置」
2. 在「基本设置」中找到「小程序备案」
3. 点击「去备案」按钮

**截图说明**：设置页面中部有「小程序备案」卡片，显示当前备案状态

### 2.3 第三步：填写主体信息

1. 主体类型：选择「组织」→「农村集体经济组织」或「居民委员会」
2. 主体名称：填写村民委员会全称（与营业执照一致）
3. 统一社会信用代码：18位代码
4. 法定代表人：村支书姓名
5. 法定代表人身份证号：18位身份证号
6. 主体通讯地址：村委会实际地址
7. 主体联系电话：村委值班电话

**截图说明**：表单字段较多，建议提前准备好材料，对照填写

### 2.4 第四步：填写管理员信息

1. 管理员姓名：村文书或村支书
2. 管理员身份证号：18位身份证号
3. 管理员手机号：用于接收工信部核验短信
4. 管理员邮箱：用于接收备案结果通知
5. 上传管理员身份证正反面照片

**截图说明**：上传身份证需清晰、完整、无遮挡

### 2.5 第五步：选择服务类目

1. 一级类目：政务民生
2. 二级类目：政务民生→基层政务
3. 备用类目：工具→信息查询

**截图说明**：类目选择影响后续审核，建议选「基层政务」

### 2.6 第六步：上传材料

1. 上传统一社会信用代码证书
2. 上传法定代表人身份证
3. 上传法定代表人任职证明
4. 上传管理员身份证
5. 上传小程序负责人承诺书（系统提供模板）

**截图说明**：所有材料需JPG/PNG格式，单张不超过2MB

### 2.7 第七步：提交审核

1. 核对所有填写信息
2. 点击「提交备案」
3. 系统生成备案订单号
4. 等待微信公众平台初审（1-2个工作日）

### 2.8 第八步：工信部短信核验

1. 初审通过后，工信部12381发送核验短信
2. 24小时内登录 https://beian.miit.gov.cn 完成核验
3. 输入短信中的验证码
4. 提交核验

**截图说明**：短信核验是备案成功的关键步骤，务必24小时内完成

### 2.9 第九步：备案完成

1. 工信部审核通过（约10-20个工作日）
2. 微信公众平台显示备案号
3. 小程序可正式上线

## 三、工信部短信核验注意事项

### 3.1 核验短信

| 项目 | 内容 |
|------|------|
| 发送号码 | 12381 |
| 短信内容 | 包含备案订单号和核验链接 |
| 有效期 | **24小时内**完成核验，逾期作废 |
| 核验网址 | https://beian.miit.gov.cn |

### 3.2 注意事项

- ⚠️ **24小时内必须完成**，否则需重新提交备案
- ⚠️ 短信可能被拦截，请检查垃圾短信文件夹
- ⚠️ 核验链接只能用备案时填写的手机号对应的微信扫码
- ⚠️ 如未收到短信，联系微信公众平台客服（电话：95173117）
- ⚠️ 短信核验是备案的最后一关，通过后即可上线

### 3.3 短信核验步骤

1. 打开短信中的链接 https://beian.miit.gov.cn
2. 输入备案订单号
3. 输入手机号收到的验证码
4. 人脸识别（用备案管理员微信扫码）
5. 提交核验
6. 显示"核验成功"

## 四、公安备案办理流程

### 4.1 是否需要公安备案

- **ICP备案完成后30日内**需办理公安备案
- 适用对象：所有在中国境内提供服务的互联网平台
- 办理机构：全国互联网安全管理服务平台

### 4.2 办理步骤

#### 步骤1：注册账号

1. 访问 https://www.beian.gov.cn
2. 点击「注册」
3. 选择单位用户注册
4. 填写村委会信息
5. 上传营业执照

#### 步骤2：填写备案信息

| 字段 | 填写内容 |
|------|---------|
| 网站名称 | XX村务连心桥 |
| 网站域名 | （微信小程序无需域名，填"无"） |
| 网站IP | （微信云开发，填云开发环境ID） |
| 网站类型 | 政府单位 |
| 服务内容 | 信息公开、政务服务 |
| 主要负责人 | 村支书 |
| 安全负责人 | 村文书 |

#### 步骤3：上传材料

- 营业执照扫描件
- 法定代表人身份证
- 网站安全管理制度
- 信息安全保密协议

#### 步骤4：提交审核

- 提交后约20个工作日审核
- 审核通过后获得公安备案号
- 备案号需在小程序底部展示

### 4.3 公安备案号展示

- 格式：京公网安备 XXXXXXXXXXXXXX号
- 展示位置：小程序「我的」页面底部
- 字号：不小于7号字

## 五、服务类目选择建议

### 5.1 推荐类目组合

| 序号 | 一级类目 | 二级类目 | 必选 | 说明 |
|------|---------|---------|------|------|
| 1 | 政务民生 | 基层政务 | ✅ 必选 | 核心类目，覆盖村务公示 |
| 2 | 政务民生 | 政务民生其他 | ✅ 必选 | 兜底类目 |
| 3 | 工具 | 信息查询 | ✅ 必选 | 办事指南、价格查询 |
| 4 | 社交 | 社区/论坛 | ⚠️ 可选 | 如开放评论功能需选 |
| 5 | 教育 | 在线教育 | ⚠️ 可选 | 如有党员学习功能 |

### 5.2 类目注意事项

- 「社交-社区/论坛」类目需提供UGC信息安全声明（见第六节）
- 涉及财务公示需提供村务监督委员会审核证明
- 涉及惠农信息需提供农业农村局授权（如有）
- 类目审核约1-3个工作日

### 5.3 审核被拒常见原因

1. ❌ 服务类目与小程序内容不符
2. ❌ 缺少UGC信息安全声明
3. ❌ 未提供所需资质证明
4. ❌ 小程序名称含敏感词
5. ❌ 简介内容过于简单

1. **内容审核制度**：所有用户提交内容（村民反映、随手拍、书记信件、失物招领）须经微信内容安全API自动检测，疑似违规内容进入人工复审队列，由内容审核员人工审核通过后方可公示。

## 八、常见问题

**Q1：备案必须办理吗？**
A：是的，2024年起微信小程序强制要求ICP备案+公安备案，未备案无法上线。

**Q2：备案需要多长时间？**
A：ICP备案约2-4周，公安备案约4-8周，建议提前2个月启动。

**Q3：村委会有资质备案吗？**
A：可以，村民委员会属于基层群众自治组织，凭统一社会信用代码证书即可备案。

**Q4：备案费用？**
A：备案本身免费，但需准备材料（如公章、扫描件），如委托第三方代办约500-2000元。

**Q5：备案后可以修改信息吗？**
A：可以，变更主体信息、管理员信息需重新提交审核，约1-2周。
