## 21.3 通用记录表 records 的扩展字段说明

### 21.3.1 type 字段的所有可能值

| type值 | 说明 | 来源云函数 |
|--------|------|-----------|
| environment | 环境卫生 | submitFeedback |
| road | 道路水利 | submitFeedback |
| dispute | 矛盾纠纷 | submitFeedback |
| cadre | 干部作风 | submitFeedback |
| safety | 安全隐患 | submitFeedback |
| other | 其他反映 | submitFeedback |
| garbage/road_safety/streetlight/sewage/illegal/other | 随手拍类型 | submitSnapshot |
| lost_found | 失物招领 | publishLostFound |

### 21.3.2 extra 字段的结构说明

extra字段用于存储该业务特有的扩展字段：

| 业务 | extra结构 |
|------|---------|
| 随手拍 | `{category: "snapshot"}` |
| 失物招领 | `{category: "lost_found", subType: "lost"/"found"}` |
| 反映 | `{}` （无扩展，字段都在主表） |

## 21.4 类型配置表 type_config 的配置说明

### 21.4.1 配置格式

```json
{
  "typeKey": "feedback",
  "typeName": "村民反映",
  "icon": "💬",
  "category": "民生服务",
  "fields": [
    {"name": "content", "type": "textarea", "required": true, "label": "详细描述"},
    {"name": "images", "type": "image", "required": false, "label": "上传图片", "max": 9},
    {"name": "urgentLevel", "type": "radio", "required": true, "label": "紧急程度", "options": ["一般","紧急","特急"]}
  ],
  "workflow": {
    "steps": ["pending", "assigned", "processing", "completed", "evaluated"]
  },
  "enabled": true,
  "sortOrder": 1,
  "visibleScope": "all",
  "handleDeadline": 3
}
```

### 21.4.2 如何新增一个业务类型

1. 在type_config集合添加记录
2. 在store/config.js的feedbackTypes或snapshotTypes数组添加对应项
3. 前端页面自动适配（通用表设计）

## 21.6 索引建议

### 21.6.1 建议添加的索引

| 集合 | 索引字段 | 用途 |
|------|---------|------|
| records | _openid + createTime | 查询我的反映 |
| records | type + createTime | 按类型查询 |
| records | status + createTime | 按状态筛选 |
| records | 'extra.category' + isPublic | 随手拍公示墙 |
| news | category + createTime | 新闻列表 |
| news | isTop + createTime | 置顶排序 |
| tasks | assigneeOpenid + status | 我的任务 |
| market_prices | productName + expired | 价格查询 |
| messages | targetOpenid + isRead | 我的消息 |
| checkin_records | _openid + checkinDate | 签到查询 |
| secretary_mails | _openid + createTime | 我的来信 |
| votes | status + createTime | 表决列表 |

### 21.6.2 复合索引建议

| 集合 | 复合索引 | 用途 |
|------|---------|------|
| records | [_openid, status, createTime] | 按状态筛选我的工单 |
| records | [type, status, createTime] | 管理端按类型+状态筛选 |
| tasks | [assigneeOpenid, status, deadline] | 我的任务按截止排序 |
| messages | [targetOpenid, isRead, createTime] | 未读消息按时间排序 |

### 21.6.3 添加索引方法

1. 云开发控制台→数据库→选择集合
2. 点击「索引管理」
3. 点击「添加索引」
4. 填写字段名和顺序（升序/降序）
5. 点击「确认」
6. 等待索引创建（大数据量需几分钟）
