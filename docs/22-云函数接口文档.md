## 22.3 公共模块 checkAdmin 的接口说明

### 22.3.1 提供的方法

| 方法 | 入参 | 出参 | 说明 |
|------|------|------|------|
| `checkAdmin(openid)` | openid(string) | boolean | 校验是否管理员 |
| `getAdminInfo(openid)` | openid(string) | admin对象/null | 获取管理员信息 |
| `checkContentSecurity(content, openid)` | content(string), openid(string) | boolean | 文本内容安全检测 |
| `checkImageSecurity(fileID)` | fileID(string) | boolean | 图片内容安全检测 |

### 22.3.2 调用方式

```javascript
const checkAdmin = require('../common/checkAdmin')

// 校验管理员
const isAdmin = await checkAdmin(OPENID)
if (!isAdmin) return { success: false, message: '无权限' }

// 内容安全检测
const isSafe = await checkAdmin.checkContentSecurity(content, OPENID)
if (!isSafe) return { success: false, message: '内容违规' }
```

## 22.4 定时触发类云函数说明

### 22.4.1 sendOverdueReminder

| 项目 | 内容 |
|------|------|
| **触发条件** | 每天8点（Cron: `0 0 8 * * * *`） |
| **执行逻辑** | 1.查询超时未完成工单；2.标记isOverdue=true；3.通知承办人；4.写入rectifications集合 |
| **通知对象** | 工单承办人（assigneeOpenid） |
| **依赖集合** | records, rectifications, logs |

### 22.4.2 generatePerformanceReport

| 项目 | 内容 |
|------|------|
| **触发条件** | 每月1号凌晨1点（Cron: `0 0 1 1 * * *`） |
| **执行逻辑** | 1.查询上月所有工单；2.按承办人分组统计；3.计算按时率/满意度/时长；4.写入performance集合 |
| **输出** | 每个承办人一条performance记录 |
| **依赖集合** | records, performance |

### 22.4.3 generateUpperReport

| 项目 | 内容 |
|------|------|
| **触发条件** | 每月1号凌晨1点（Cron: `0 0 1 1 * * *`） |
| **执行逻辑** | 1.并行统计5大块数据（工单/公示/任务/项目/党建）；2.计算满意度；3.写入upper_reports集合 |
| **输出** | 一条upper_reports记录，含summary对象 |
| **依赖集合** | records, news, notices, tasks, projects, team_members, upper_reports |

## 22.5 错误码总览

### 22.5.1 通用错误码

| 错误码 | 含义 | 处理方法 |
|--------|------|---------|
| -1 | 系统繁忙 | 稍后重试 |
| 0 | 成功 | - |
| 40029 | 无效的code | 检查登录态 |
| 45011 | API限制 | 降低调用频率 |

### 22.5.2 云函数错误码

| 错误码 | 含义 | 处理方法 |
|--------|------|---------|
| -501001 | 集合已存在 | 忽略（initDatabase） |
| -502003 | 参数错误 | 检查入参 |
| -503001 | 权限不足 | 检查安全规则或管理员权限 |

### 22.5.3 内容安全错误码

| 错误码 | 含义 | 处理方法 |
|--------|------|---------|
| 0 | 内容正常 | 通过 |
| 87013 | 确认违规 | 拒绝+通知用户 |
| 87014 | 疑似违规 | 进入人工复审 |

### 22.5.4 订阅消息错误码

| 错误码 | 含义 | 处理方法 |
|--------|------|---------|
| 0 | 成功 | - |
| 40037 | 模板ID错误 | 检查模板ID |
| 43101 | 用户未授权 | 引导用户授权 |
| 42043 | 模板已下架 | 重新申请 |
| 47003 | 参数格式错误 | 检查关键词类型 |

### 22.5.5 业务错误信息

| 场景 | message | 处理方法 |
|------|---------|---------|
| 提交工单失败 | "提交失败，请重试" | 检查网络+内容 |
| 内容违规 | "内容包含违规信息，请修改后重试" | 修改内容 |
| 无权限 | "无操作权限" | 检查管理员身份 |
| 工单不存在 | "工单不存在" | 检查recordId |
| 已评价 | "已评价过，不能重复评价" | - |
| 超过图片限制 | "最多上传9张图片" | 减少图片数量 |
