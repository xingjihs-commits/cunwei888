### 17.3.2 首次进入弹窗实现

在App.vue的onLaunch中增加：

```javascript
onLaunch(() => {
  const agreed = uni.getStorageSync('agreementAgreed')
  if (!agreed) {
    uni.showModal({
      title: '服务协议与隐私政策',
      content: '欢迎使用村务连心桥，使用前请阅读《用户协议》和《隐私政策》',
      confirmText: '同意',
      cancelText: '拒绝',
      success(res) {
        if (res.confirm) {
          uni.setStorageSync('agreementAgreed', true)
        }
      }
    })
  }
})
```

## 17.4 服务类目选择

### 17.4.1 推荐类目

| 序号 | 一级类目 | 二级类目 | 必选 | 说明 |
|------|---------|---------|------|------|
| 1 | 政务民生 | 基层政务 | ✅ 必选 | 核心类目，覆盖村务公示 |
| 2 | 政务民生 | 政务民生其他 | ✅ 必选 | 兜底类目 |
| 3 | 工具 | 信息查询 | ✅ 必选 | 办事指南、价格查询 |

### 17.4.2 选择理由

- 「政务民生-基层政务」：本平台为村委会主办，符合基层政务定位
- 「工具-信息查询」：办事指南、惠农价格查询属于信息查询

### 17.4.3 需要提供的资质

| 类目 | 所需资质 |
|------|---------|
| 政务民生 | 村委会统一社会信用代码证书 |
| 工具 | 无需资质 |

### 17.4.4 审核注意事项

- 类目审核约1-3个工作日
- 被拒常见原因：类目与内容不符、资质不全
- 应对：补全资质、调整类目

## 17.6 审核常见驳回原因与应对

### 17.6.1 类目选择错误

| 现象 | 应对方法 |
|------|---------|
| 提示"类目与内容不符" | 1.检查内容是否含UGC；2.如含UGC改选「社交-社区/论坛」；3.重新提交审核 |

### 17.6.2 UGC无审核机制

| 现象 | 应对方法 |
|------|---------|
| 提示"UGC内容无安全审核" | 1.确认msgSecCheck已集成；2.确认imgSecCheck已集成；3.提交UGC信息安全声明；4.重新提交 |

### 17.6.3 隐私政策缺失

| 现象 | 应对方法 |
|------|---------|
| 提示"未提供隐私政策" | 1.在pages/agreement/index.vue展示隐私政策；2.首次进入弹窗引导同意；3.重新提交 |

### 17.6.4 功能不完整

| 现象 | 应对方法 |
|------|---------|
| 提示"功能不完整" | 1.检查所有页面是否可正常打开；2.补充initDatabase示例数据；3.确保审核员可体验完整流程；4.重新提交 |

### 17.6.5 内容涉及敏感

| 现象 | 应对方法 |
|------|---------|
| 提示"内容敏感" | 1.检查示例数据是否含敏感词；2.修改敏感内容；3.重新提交 |

### 17.6.6 页面打不开

| 现象 | 应对方法 |
|------|---------|
| 提示"页面无法访问" | 1.检查云函数是否全部部署；2.检查环境ID是否正确；3.检查数据库集合是否创建；4.重新提交 |

### 17.6.7 驳回处理流程

1. 查看驳回原因（微信公众平台→审核记录）
2. 按原因分类应对（见上表）
3. 修复后重新提交
4. 一般24小时内审核完成

## 17.7 审核通过后的发布

### 17.7.1 审核通过后如何发布

1. 微信公众平台→版本管理
2. 找到已通过审核的版本
3. 点击「发布」
4. 确认发布
5. 约5-10分钟全网上线

### 17.7.2 发布后如何监控

| 监控项 | 方法 | 频率 |
|--------|------|------|
| 错误日志 | 云开发控制台→云函数→日志 | 每天 |
| 用户反馈 | 消息中心+书记信箱 | 每天 |
| 工单超时 | 考核看板 | 每周 |
| 数据备份 | 每月1日导出 | 每月 |

### 17.7.3 发现问题如何回滚

1. 微信公众平台→版本管理
2. 找到上一个稳定版本
3. 点击「回滚」
4. 确认回滚
5. 约5-10分钟生效

### 17.7.4 版本更新流程

1. 修改代码
2. HBuilderX重新编译
3. 上传新版本（微信公众平台→版本管理→上传）
4. 提交审核
5. 审核通过后发布
6. 通知村民更新
