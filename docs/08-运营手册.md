# 村务连心桥运营手册

**适用对象**：村支书、村文书、村委委员、信息发布员
**生效日期**：2026年1月1日

---

## 一、运营岗位表

### 1.1 岗位设置

本平台运营需设置以下4个岗位（可一人多岗，但建议至少2人分工）：

| 岗位 | 人数 | 主要职责 | 工作频率 | 适任人选 |
|------|------|---------|---------|---------|
| **平台管理员** | 1人 | 系统配置、账号管理、权限分配、数据备份 | 每周2小时 | 村文书 |
| **信息发布员** | 1-2人 | 新闻/公示/广播/价格/任务发布 | 每天30分钟 | 村文书+村委委员 |
| **工单处理员** | 2-3人 | 工单派单、处理、回复、催办 | 每天1小时 | 村两委班子成员 |
| **内容审核员** | 1人 | 内容安全复审、违规处理 | 每天30分钟 | 村支书或文书 |

### 1.2 岗位职责详解

#### 平台管理员（村文书）

| 职责 | 频率 | 说明 |
|------|------|------|
| 系统配置维护 | 每月1次 | 模块开关、村信息、紧急电话 |
| 管理员白名单维护 | 换届/调动时 | 离任即移除、新任即添加 |
| 数据备份 | 每月1日 | 导出29个集合并归档 |
| 系统监控 | 每周1次 | 检查云函数运行情况、错误日志 |
| 用户认证审核 | 收到申请24小时内 | 审核村民实名认证 |
| 数据统计 | 每月1次 | 生成对上汇报数据 |

#### 信息发布员（村文书+村委委员）

| 职责 | 频率 | 说明 |
|------|------|------|
| 村务新闻发布 | 每周2-3条 | 领导视察、村务动态、民生实事 |
| 信息公示发布 | 每月3-5条 | 党务/村务/财务/惠农/应急 |
| 书记广播发布 | 每周1-2条 | 紧急通知、重要事项 |
| 惠农价格更新 | 每周1次 | 主要农产品价格 |
| 政策任务发布 | 上级下发后 | 及时发布落实任务 |
| 项目收益公示 | 项目完成后 | 集体项目收益情况 |

#### 工单处理员（村两委班子成员）

| 职责 | 频率 | 说明 |
|------|------|------|
| 工单派单 | 收到后4小时内 | 根据事项类型派给相应承办人 |
| 工单处理 | 3个工作日内 | 派单后及时处理 |
| 工单回复 | 处理完成后 | 填写处理结果+照片 |
| 超时工单催办 | 每天8点 | 定时催办系统已自动触发 |
| 书记信箱回复 | 2个工作日内 | 书记本人或授权回复 |
| 随手拍处理 | 2个工作日内 | 公示墙问题处理 |

#### 内容审核员（村支书或文书）

| 职责 | 频率 | 说明 |
|------|------|------|
| 内容安全复审 | 每天1次 | 复审疑似违规内容 |
| 违规内容处理 | 发现后立即 | 删除违规内容+通知提交者 |
| 用户投诉处理 | 收到后24小时内 | 处理内容相关投诉 |
| 重要内容审核 | 发布前 | 书记广播、重要公示发布前审核 |

## 六、推广三步走

### 6.1 第一步：种子用户（第1-2周）

**目标**：100名种子用户

| 措施 | 具体做法 | 责任人 |
|------|---------|--------|
| 村两委+党员带头 | 全体村两委、党员必须注册使用 | 村支书 |
| 村民代表推广 | 50名村民代表注册 | 文书 |
| 骨干村民引导 | 种植大户、致富带头人注册 | 文书 |
| 上门帮注册 | 对不会操作的老人上门帮注册 | 网格员 |

### 6.2 第二步：线下扫码（第3-4周）

**目标**：300名活跃用户

| 措施 | 具体做法 | 责任人 |
|------|---------|--------|
| 张贴二维码 | 村委办公室、卫生室、小卖部、文化广场张贴小程序码 | 文书 |
| 大喇叭宣传 | 每天定时广播小程序功能 | 书记 |
| 现场指导 | 赶集日村委设摊，现场指导使用 | 全体 |
| 入户推广 | 网格员入户推广，重点指导老人 | 网格员 |
| 微信群推送 | 各村组微信群推送小程序码 | 各群主 |

### 6.3 第三步：微信群联动（持续）

**目标**：500+用户，月活率60%+

| 措施 | 具体做法 | 责任人 |
|------|---------|--------|
| 村务群绑定 | 各村组微信群绑定小程序 | 各群主 |
| 内容同步 | 小程序发布的新闻同步到微信群 | 文书 |
| 互动激励 | 在小程序反映的优先处理 | 工单处理员 |
| 功能引导 | 微信群引导村民使用办事指南、惠农价格等 | 文书 |
| 老人帮扶 | 帮老人绑定家庭账号，子女代操作 | 网格员 |

## 七、四重触达机制

### 7.1 触达渠道

本平台采用**四重触达机制**，确保信息送达每一位村民：

| 渠道 | 触达方式 | 适用场景 | 覆盖率 |
|------|---------|---------|--------|
| **小程序** | 订阅消息推送 | 工单状态、价格更新、任务派发 | 70% |
| **微信群** | 群内同步发布 | 重要新闻、公示、广播 | 90% |
| **大喇叭** | 每天定时广播 | 紧急通知、农事提醒 | 100% |
| **公示栏** | 纸质张贴 | 财务公示、重要公告 | 100% |

### 7.2 触达场景对照

| 场景 | 小程序 | 微信群 | 大喇叭 | 公示栏 |
|------|--------|--------|--------|--------|
| 紧急通知（如防汛） | ✅ | ✅ | ✅ | ✅ |
| 书记广播 | ✅ | ✅ | ✅ | - |
| 工单状态更新 | ✅ | - | - | - |
| 价格更新 | ✅ | ✅ | - | - |
| 财务公示 | ✅ | ✅ | ✅ | ✅ |

| 农事提醒 | ✅ | ✅ | ✅ | - |

### 7.3 触达频率

| 内容类型 | 小程序 | 微信群 | 大喇叭 | 公示栏 |
