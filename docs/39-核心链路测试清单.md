## 39.3 异常路径测试

### A. 未登录访问 admin 页面
- [ ] 未认证 openid 直接访问 pages/admin/dashboard
- [ ] 验证：被 useAdminGuard 拦截，toast "无管理员权限"，1.5s 后 navigateBack

### B. 弱网重复点击
- [ ] 网络限速到 2G，连续点击"提交反映"3 次
- [ ] 验证：acquireLock 拦截第 2、3 次，toast "请勿重复提交"
- [ ] 验证：records 集合只新增 1 条

### C. 内容安全失败
- [ ] 提交反映时输入违规词（如政治敏感词）
- [ ] 验证：checkContentSecurity 返回 false，toast "内容包含违规信息"
- [ ] 验证：records 集合不新增

### D. 图片上传失败
- [ ] 模拟云存储权限失效
- [ ] 提交反映附 2 张图
- [ ] 验证：uploadImages 返回 failed=2
- [ ] 验证：弹窗"2 张图片上传失败，是否继续？"
- [ ] 验证：选"否"后 cleanupFileIDs 清理已上传的文件

### E. 网络断网
- [ ] 提交反映时手机开启飞行模式
- [ ] 验证：toast "当前网络不可用"
- [ ] 关闭飞行模式 → 重新提交
- [ ] 验证：草稿已保留，能继续提交

### F. 定时器失效
- [ ] 临时禁用 sendOverdueReminder 定时器
- [ ] 48h 后验证告警触发
