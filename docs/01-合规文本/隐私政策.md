# 村务连心桥隐私政策

**生效日期**：2026年1月1日

---

## 一、引言

村务连心桥（以下简称"本平台"）由本村民委员会主办，高度重视用户隐私保护。本政策详细说明我们如何收集、使用、存储、保护您的个人信息，以及您享有的权利。请您仔细阅读本政策，了解我们处理个人信息的方式。使用本平台即视为您同意本政策所述的信息处理方式。

---

## 二、我们收集哪些信息

### 2.1 您主动提供的信息

| 信息类型 | 具体内容 | 收集场景 | 用途 |
|---------|---------|---------|------|
| 微信基本信息 | 昵称、头像 | 首次登录 | 显示身份 |
| 真实姓名 | 身份证真实姓名 | 实名认证 | 身份核验 |
| 身份证号 | 18位身份证号 | 实名认证 | 身份核验 |
| 手机号码 | 11位手机号 | 实名认证 | 联系、订阅消息 |
| 所在村组 | 如"三组" | 实名认证 | 工单分派 |
| 详细地址 | 如"XX村XX号" | 实名认证（选填） | 工单分派 |
| 反映内容 | 文字、图片 | 提交反映 | 工单处理 |
| 随手拍内容 | 照片、文字、位置 | 提交随手拍 | 问题处理+公示 |
| 信件内容 | 主题、文字 | 书记信箱 | 书记查阅回复 |
| 失物信息 | 标题、描述、图片 | 失物招领 | 公示 |

### 2.2 自动收集的信息

| 信息类型 | 收集方式 | 用途 |
|---------|---------|------|
| OpenID | 微信登录自动获取 | 用户身份标识 |
| 位置信息 | 随手拍提交时授权获取 | 问题定位 |
| 录音文件 | 语音输入时授权录音 | 语音转文字 |
| 设备信息 | 系统自动获取 | 故障排查 |
| 操作日志 | 系统自动记录 | 安全审计 |

### 2.3 不收集的信息

- 我们不收集您的银行卡、支付密码等财务信息
- 我们不持续追踪您的位置（仅在您主动使用相关功能时获取）
- 我们不收集您的通讯录、相册等其他隐私信息
- 我们不向第三方出售您的个人信息

---

## 三、我们为什么收集这些信息

### 3.1 提供服务的必要信息

- **身份核验**：实名认证信息用于确认您是本村村民，确保工单受理的准确性
- **工单处理**：反映内容、随手拍内容用于村委处理您的诉求
- **联系通知**：手机号用于工单状态更新、任务派发等订阅消息推送
- **位置定位**：随手拍位置用于村委快速定位问题地点
- **公示展示**：随手拍、失物招领等内容公示在公示墙，供全村查看

### 3.2 改进服务的信息

- **操作日志**：用于分析功能使用情况，优化产品设计
- **设备信息**：用于排查兼容性问题
- **反馈建议**：用于完善服务功能

### 3.3 法律法规要求

- 按《网络安全法》《个人信息保护法》《数据安全法》要求保留必要日志
- 配合公安、网信等部门依法调取数据

## 四、我们如何保护您的信息

### 4.1 技术措施

| 措施 | 说明 |
|------|------|
| 云开发安全规则 | 数据库集合配置安全规则，仅本人和管理员可读写个人数据 |
| 传输加密 | HTTPS 加密传输 |
| 内容安全检测 | 微信内容安全API自动检测文本和图片 |
| 访问权限控制 | 云函数管理员SDK，仅授权函数可访问数据 |
| 防重复提交 | 锁机制防止误操作 |
| 图片压缩上传 | 减少存储压力和传输风险 |

### 4.2 管理措施

| 措施 | 说明 |
|------|------|
| 管理员白名单 | 仅村委会认定的管理员可访问后台数据 |
| 操作日志 | 所有管理操作留痕，可追溯 |
| 换届交接 | 换届时离任管理员账号立即移除 |
| 数据备份 | 每月数据导出备份，安全存储 |
| 保密协议 | 管理员签署保密承诺 |

### 4.3 数据脱敏

- 手机号在展示时脱敏显示（如138****8888）
- 身份证号不公开展示
- 书记信箱匿名提交时，书记无法看到提交者身份

## 五、您有什么权利

### 5.1 查看权

- 您可在"个人中心→个人信息"查看自己的认证信息
- 您可在"我的反映"查看自己提交的所有工单
- 您可在"我的来信"查看与书记的通信记录
- 您可在"每日签到"查看自己的签到历史

### 5.2 更正权

- 您可联系村委办公室（电话：0571-XXXXXXXX）申请更正错误信息
- 更正范围包括：姓名、手机号、村组、地址等
- 身份证号一经认证不可自行更正，确需更正需带身份证到村委现场办理

### 5.3 删除权

- 您可联系村委申请删除个人信息
- 删除范围：个人认证信息、签到记录、订阅记录
- 不可删除的数据：已公示的反映/随手拍（涉及公共利益，按公示期保留）、已处理工单（涉及治理留痕，按档案管理保留）、操作日志（按法规保留）

### 5.4 撤回同意权

- 您可关闭位置授权（系统设置→权限管理）
- 您可关闭录音授权
- 您可关闭相机授权
- 您可取消订阅消息（每条订阅消息可单独取消）
- 您可停止使用本平台

### 5.5 投诉权

- 如您认为我们侵犯了您的合法权益，可向村委投诉
- 如村委未及时处理，可向上级街道办/乡镇政府投诉
- 也可向网信办（12377）、消协（12315）投诉

## 六、数据保存期限

### 6.1 个人信息保存期限

| 数据类型 | 保存期限 | 说明 |
|---------|---------|------|
| 实名认证信息 | 认证有效期内+60天 | 注销后保留60天备查 |
| 反映工单 | 处理完成后保留3年 | 治理留痕需要 |
| 随手拍记录 | 公示期结束后保留1年 | 公示追溯 |
| 书记信件 | 回复后保留1年 | 通信记录 |
| 操作日志 | 保留3年 | 法规要求 |
| 签到记录 | 保留1年 | 关怀记录 |
| 订阅记录 | 取消订阅后立即删除 | - |

### 6.2 数据删除流程

- 用户主动申请删除：联系村委→核实身份→7个工作日内处理→书面确认
- 平台主动删除：超过保存期限的数据，系统自动清理
- 法律法规要求：按相关部门要求保留或删除

### 6.3 数据归属

- 所有数据归**本村集体所有**，存储在微信云开发环境
- 任何个人（含村支书）不得将数据带离本村
- 换届时数据完整移交新一届村委
- 平台迁移时数据由村集体决定去向

## 七、第三方共享

### 7.1 我们不会向以下第三方共享

- 不向商业广告商共享
- 不向数据中介共享
- 不向与本平台服务无关的第三方共享

### 7.2 必要的第三方服务

| 服务商 | 共享信息 | 用途 |
|--------|---------|------|
| 微信云开发 | 全部数据 | 数据存储（已签署数据处理协议） |
| 微信内容安全API | 文本、图片 | 内容安全检测 |
| 微信订阅消息 | 通知内容 | 消息推送 |
| 百度/讯飞ASR（可选） | 录音文件 | 语音转文字 |

### 7.3 法律法规要求

- 公安机关依法调取，我们配合提供
- 网信部门依法监管，我们配合检查
- 法院传票要求，我们配合执行

## 八、未成年人保护

本平台主要面向成年村民，不主动收集未成年人信息。如您发现我们误收集了未成年人信息，请联系村委，我们将在7个工作日内删除。
