# 31 - UI 布局规范

> 本文档定义"村务连心桥"项目的统一布局规范。所有页面必须遵守，不得自写硬编码数值。

## 31.1 间距规范（4 倍数体系）

| 变量 | 值 | 用途 |
|------|------|------|
| `$space-xs` | 8rpx | 极小间距：标签内边距、icon 间距 |
| `$space-sm` | 12rpx | 小间距：按钮内边距、紧凑元素 |
| `$space-md` | 16rpx | 中间距：输入框内边距、行间距 |
| `$space-lg` | 24rpx | 大间距：卡片内边距、卡片间距 |
| `$space-xl` | 32rpx | 页面左右边距 |
| `$space-2xl` | 48rpx | 大段间距：章节间距 |

**兼容旧变量名**（保留向后兼容）：
- `$page-padding` = `$space-xl` = 32rpx
- `$card-padding` = `$space-lg` = 24rpx
- `$card-gap` = `$space-lg` = 24rpx

### 使用规则
- ❌ 禁止：`padding: 20rpx;`（不是 4 倍数）
- ❌ 禁止：`margin: 15rpx;`（不是 4 倍数）
- ✅ 推荐：`padding: $card-padding;`
- ✅ 推荐：`padding: $space-md $space-lg;`（16rpx + 24rpx）

## 31.2 圆角规范

| 变量 | 值 | 用途 |
|------|------|------|
| `$radius-xs` | 4rpx | 极小圆角：标签、徽章 |
| `$radius-sm` | 8rpx | 小圆角：按钮、输入框 |
| `$radius-md` | 12rpx | 中圆角：图片缩略图 |
| `$radius-lg` | 16rpx | 大圆角：卡片 |
| `$radius-xl` | 24rpx | 超大圆角：弹窗、特殊卡片 |
| `$radius-full` | 9999rpx | 全圆角：圆形按钮、头像 |

**兼容旧变量名**：
- `$card-radius` = `$radius-lg` = 16rpx
- `$btn-radius` = `$radius-full` = 9999rpx（胶囊形按钮）

### 使用规则
- 卡片：`border-radius: $card-radius;`
- 按钮：`border-radius: $btn-radius;`
- 输入框：`border-radius: $radius-sm;`
- 图片：`border-radius: $radius-md;`

## 31.3 阴影规范

| 变量 | 值 | 用途 |
|------|------|------|
| `$shadow-sm` | `0 2rpx 8rpx rgba(0,0,0,0.04)` | 轻阴影：次要卡片 |
| `$shadow-md` | `0 2rpx 12rpx rgba(0,0,0,0.06)` | 中阴影：主要卡片（默认） |
| `$shadow-lg` | `0 4rpx 16rpx rgba(0,0,0,0.08)` | 重阴影：弹窗、置顶卡片 |
| `$shadow-top` | `0 -2rpx 12rpx rgba(0,0,0,0.06)` | 顶部阴影：底部固定栏 |

**兼容旧变量名**：
- `$card-shadow` = `$shadow-md`

### 使用规则
- 卡片：`box-shadow: $card-shadow;`
- 底部固定栏：`box-shadow: $shadow-top;`
- 弹窗：`box-shadow: $shadow-lg;`
- ❌ 禁止：`box-shadow: 0 4rpx 8rpx rgba(0,0,0,0.2);`（自写数值）

## 31.4 对齐规范

### 文字对齐
| 元素 | 对齐方式 |
|------|---------|
| 卡片标题 | 左对齐（默认） |
| 正文 | 左对齐 |
| 状态标签 | 居中 |
| 数字（价格、统计） | 右对齐 |
| 按钮文字 | 居中 |
| 错误提示 | 左对齐 |

### 元素对齐
- 同一行内的元素必须**垂直居中**：`align-items: center;`
- 列表项左右两侧信息必须**对齐**：左侧文字 flex:1，右侧固定宽度
- 卡片标题、正文、按钮的**左边界对齐**

## 31.5 字号层级

| 变量 | 值 | 用途 |
|------|------|------|
| `$font-title` | 40rpx | 页面标题 |
| `$font-card-title` | 36rpx | 卡片标题 |
| `$font-body` | 32rpx | 正文（适老化最低） |
| `$font-sub` | 28rpx | 辅助文字 |
| `$font-btn` | 36rpx | 按钮文字 |
| `$font-number` | 48rpx | 数字强调 |
| `$font-large-number` | 56rpx | 大数字（看板排行） |
| `$font-micro` | 24rpx | 最小字号（仅辅助标签，不用于正文） |

### 层级规则
- 标题 > 副标题 > 正文 > 辅助文字
- 重要信息用 `$font-body` 或更大
- 次要信息用 `$font-sub`
- ❌ 禁止：正文用 `$font-micro`（24rpx 太小，老人看不清）

## 31.6 颜色层级

### 主色
- `$primary` #C41E24：顶部栏、主按钮、选中态
- `$primary-dark` #A01820：按压态
- `$primary-light` #FDE8E8：标签底色、选中背景

### 辅助色
- `$gold` #D4A843：荣誉、表彰、奖牌
- `$gold-light` #F5E6C8：荣誉卡片背景

### 中性色
- `$white` #FFFFFF：卡片
- `$bg` #FAF7F2：页面底色
- `$text-main` #212121：标题、正文
- `$text-sub` #757575：辅助说明
- `$text-weak` #9E9E9E：占位、禁用
- `$border` #EEEEEE：分割线

### 功能色
- `$success` #2E7D32：已完成、通过
- `$warning` #E65100：超时、待处理
- `$danger` #C62828：拒绝、紧急
- `$price` #E63946：价格数字

### 层级规则
- 标题：`$text-main`
- 正文：`$text-main`
- 辅助：`$text-sub`
- 占位/禁用：`$text-weak`
- ❌ 禁止：直接写 `color: #212121;`（必须用变量）

## 31.7 公共样式复用

### 卡片样式
所有卡片**必须复用** `.card` 公共类，不要自己写：
```vue
<view class="card">
  <!-- 内容 -->
</view>
```

❌ 禁止：
```vue
<view style="background: #fff; border-radius: 16rpx; padding: 24rpx; box-shadow: 0 2rpx 12rpx rgba(0,0,0,0.06);">
  <!-- 内容 -->
</view>
```

### 按钮样式
主按钮用 `.btn-primary`，次按钮用 `.btn-default`。

### 页面容器
所有页面根元素用 `.page-container`。

## 31.8 表单布局规范

### 输入框
- 高度：`$btn-height`（88rpx，适老化）
- 圆角：`$radius-sm`
- 内边距：`$space-md $space-lg`
- 背景：`$bg`
- 字号：`$font-body`

### 表单组间距
- 表单项之间：`$space-2xl`（48rpx）
- 标签与输入框：`$space-sm`（12rpx）
- 错误提示与输入框：`$space-xs`（8rpx）

### 提交按钮
- 位置：底部固定栏（`position: fixed; bottom: 0;`）
- 高度：`$btn-height`（88rpx）
- 内边距：`$card-gap $page-padding`
- 底部安全区：`padding-bottom: calc(#{$card-gap} + env(safe-area-inset-bottom));`

## 31.9 列表布局规范

### 列表项高度
- 标准列表项：min-height 120rpx
- 紧凑列表项：min-height 80rpx
- 所有同列表项**高度一致**

### 列表项内部布局
- 左侧图标：固定宽度 60rpx
- 中间文字：`flex: 1; min-width: 0;`（防溢出）
- 右侧辅助：固定宽度
- 长文本：`white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`

### 列表项间距
- 列表项之间：`$space-sm`（12rpx）
- 列表与标题：`$card-gap`（24rpx）

## 31.10 详情页布局规范

### 信息分组
详情页按以下顺序分组，每组一个 `.card`：
1. 状态 banner（醒目，整行）
2. 基本信息（事项类型/时间/紧急程度）
3. 主体内容（诉求/正文/图片）
4. 处理信息（责任人/回复/时长）
5. 操作区（评价/举报/分享）

### 卡片间距
- 卡片之间：`$card-gap`（24rpx）
- 卡片标题与内容：`$card-gap`（24rpx）
- 信息行之间：`$space-md`（16rpx）

### 图片网格
- 一行 3 列：`grid-template-columns: repeat(3, 1fr);`
- 间距：`$space-sm`（12rpx）
- 宽高比：1:1
- 圆角：`$radius-md`（12rpx）

## 31.11 看板布局规范

### 统计概览
- 4 宫格：`grid-template-columns: repeat(4, 1fr);` 或 2x2
- 每格高度一致
- 数字字号：`$font-large-number`（56rpx）
- 标签字号：`$font-sub`（28rpx）

### 进度条
- 高度：24rpx
- 圆角：`$radius-full`
- 背景色：`$border`
- 填充色：`linear-gradient(90deg, $primary, $gold);`

### 排行榜
- 奖牌色：`$medal-gold` / `$medal-silver` / `$medal-bronze`
- 排名圆圈：48rpx x 48rpx 圆形
- 姓名字号：`$font-body`
- 数据字号：`$font-sub`

## 31.12 适老化布局

### 字号
- 正文 ≥ 32rpx（`$font-body`）
- 标题 ≥ 40rpx（`$font-title`）
- 按钮 ≥ 36rpx（`$font-btn`）
- ❌ 禁止正文用 < 32rpx

### 行高
- 正文行高：1.6-1.8
- 标题行高：1.4
- ❌ 禁止行高 < 1.4

### 点击区
- 按钮高度 ≥ 88rpx（`$btn-height`）
- 列表项高度 ≥ 120rpx
- 图标点击区 ≥ 60rpx x 60rpx

### 留白
- 卡片内边距 ≥ 24rpx（`$card-padding`）
- 卡片间距 ≥ 24rpx（`$card-gap`）
- 页面边距 ≥ 32rpx（`$page-padding`）
- 章节间距 ≥ 48rpx（`$space-2xl`）

## 31.13 禁止事项

1. ❌ 禁止直接写色值：`color: #C41E24;` → 必须用 `color: $primary;`
2. ❌ 禁止自写卡片样式：必须复用 `.card`
3. ❌ 禁止硬编码间距：必须用 `$space-*` 变量
4. ❌ 禁止硬编码圆角：必须用 `$radius-*` 变量
5. ❌ 禁止硬编码阴影：必须用 `$shadow-*` 变量
6. ❌ 禁止正文用 < 32rpx 字号
7. ❌ 禁止行高 < 1.4
8. ❌ 禁止按钮高度 < 88rpx
9. ❌ 禁止一屏塞太多内容（用"更多 >"分页）
10. ❌ 禁止多个元素抢焦点（每页一个视觉重心）
