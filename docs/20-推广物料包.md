# 第二十部分：推广物料包

**适用对象**：村支书、村文书、网格员
**目的**：提供可直接使用的推广物料，提升村民注册率和活跃度

## 20.1 公示栏海报模板

### 20.1.1 尺寸建议

| 用途 | 尺寸 | 说明 |
|------|------|------|
| 村委公示栏 | A2（420×594mm） | 张贴在村委办公室外公示栏 |
| 村卫生室 | A3（297×420mm） | 张贴在卫生室门口 |
| 小卖部 | A3 | 张贴在小卖部入口 |
| 文化广场 | A2 | 张贴在文化广场公告栏 |

### 20.1.2 内容要素

海报必须包含以下要素：
1. **小程序名称**：「XX村务连心桥」（大字标题）
2. **小程序二维码**：占海报面积1/4，清晰可扫
3. **一句话说明**：「村里的贴心平台，办事不用跑」
4. **使用步骤**：3步（扫码→授权→使用）
5. **村委联系电话**：0571-XXXXXXXX
6. **村委会落款**：XX村民委员会

### 20.1.3 设计要点

- **主色**：中国红 #C41E24
- **辅助色**：金色 #D4A843
- **字号**：标题≥60pt，正文≥24pt（老人可看清）
- **二维码**：≥5×5cm，确保扫码成功
- **背景**：浅米色 #FAF7F2

## 20.5 打印版使用手册

### 20.5.1 适合A4打印的简化版使用指南

**纸张**：A4（210×297mm）
**字号**：正文14pt（老人可看清）
**页数**：2页（双面打印1张纸）
**字体**：宋体（清晰易读）

### 20.5.2 内容模板

```
══════════════════════════
  村务连心桥使用指南
  （打印版）
══════════════════════════

一、什么是村务连心桥？

村务连心桥是咱们村的微信小程序，
可以在手机上：
- 查看村务新闻
- 提交问题反映
- 看财务公示
- 查惠农价格
- 给书记写信
- 查办事指南

二、怎么用？

第1步：打开微信
第2步：搜索"XX村务连心桥"
第3步：点击进入小程序
第4步：注册认证（首次）

三、主要功能

1. 书记信箱
   直接给书记写信，不经派单
   支持匿名

2. 村民反映
   提交问题，3天内处理
   可查进度

3. 随手拍
   拍照反映问题，公示墙展示

4. 信息公示
   党务/村务/财务/惠农/应急

   实时价格，可订阅提醒

6. 办事指南
   低保/医保/宅基地怎么办

7. 一事一议
   在线投票，民主决策

8. 消息中心
   所有通知，一目了然

四、不会打字怎么办？

找"按住 说话"按钮
长按说话，松开后自动识别成文字

五、收不到通知怎么办？

微信→我→设置→消息通知
→找到"村务连心桥"→开启

六、有问题找谁？
```
