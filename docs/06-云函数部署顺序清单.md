## 二、部署方法

### 方法1：批量部署（推荐）

1. 用HBuilderX右键`cloudfunctions`文件夹
2. 选择"上传部署所有云函数"
3. 等待全部部署完成（约10-20分钟）

### 方法2：按批次手动部署

按上表顺序，右键每个云函数文件夹 → "上传部署"

### 方法3：微信开发者工具

1. 打开微信开发者工具
2. cloudfunctions目录右键 → "上传并部署所有云函数"

## 四、initDatabase云函数完整代码

### 4.1 index.js

```javascript
/**
 * initDatabase/index.js - 数据库初始化
 * 用途：一键创建所有集合并插入示例数据
 * 使用：云开发控制台部署后调用一次即可
 */
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })
const db = cloud.database()

// 集合清单（v2.0 完整版，共29个）
const COLLECTIONS = [
  'records', 'type_config', 'users', 'admins', 'notices',
  'projects', 'market_prices', 'tasks', 'task_progress',
  'news', 'team_members', 'performance', 'rectifications',
  'subscriptions', 'logs', 'module_config', 'audit_queue', 'faq',
  // v2.0 新增集合
  'secretary_mails', 'broadcasts', 'service_guides',
  'upper_reports', 'meetings', 'votes', 'finance_reports',
  'messages', 'subsidies', 'agri_calendar', 'checkin_records'
]

exports.main = async (event, context) => {
  const results = { collections: [], initData: [], errors: [] }
  
  // 1. 创建集合
  for (const name of COLLECTIONS) {
    try {
      await db.createCollection(name)
      results.collections.push(`✓ ${name}`)
    } catch (err) {
      if (err.errCode === -501001 || (err.message && err.message.includes('already exists'))) {
        results.collections.push(`= ${name} (已存在)`)
      } else {
        results.errors.push(`创建${name}失败: ${err.message || ''}`)
      }
    }
  }
  
  // 2. 初始化示例数据
  try {
    const initData = require('./initData')
    results.initData = await initData()
  } catch (err) {
    results.errors.push(`初始化数据失败: ${err.message || ''}`)
  }
  
  return {
    success: true,
    message: '数据库初始化完成',
    results: results
  }
}
```

### 4.2 initData.js（示例数据插入）

代码较长，详见项目内 `cloudfunctions/initDatabase/initData.js`，包含以下集合的示例数据：

- module_config：村信息+9模块开关
- team_members：2名班子成员
- news：1条村务新闻
- notices：1条信息公示
- market_prices：2条惠农价格
- faq：1条问答
- service_guides：3条办事指南（低保/医保/宅基地）
- broadcasts：1条书记广播
- finance_reports：1条财务报表
- agri_calendar：12个月农事日历
- meetings：1个示例会议
- votes：1个示例表决

## 五、定时触发器配置

部署完定时触发类云函数后，需在云开发控制台配置触发器：

### 5.1 sendOverdueReminder（每天8点催办）

| 配置项 | 值 |
|--------|-----|
| 触发器类型 | 定时触发 |
| Cron表达式 | `0 0 8 * * * *` |
| 触发时间 | 每天上午8:00 |
| 用途 | 检查超时工单+通知承办人+写入整改记录 |

### 5.2 generatePerformanceReport（每月1号考核）

| 配置项 | 值 |

| 用途 | 自动生成上月考核统计 |

## 六、部署常见问题

### Q1：部署报错"找不到common/checkAdmin模块"

A：common文件夹需要单独部署。右键`cloudfunctions/common`文件夹→"上传部署为公共模块"。

### Q2：initDatabase调用后部分集合创建失败

A：可能是权限不足。检查云开发环境是否开通，管理员是否有数据库创建权限。

### Q3：定时触发器不生效

A：1. 确认云函数已部署；2. 在云开发控制台→云函数→触发器中检查是否配置成功；3. Cron表达式时区为UTC+8。

### Q4：部署后小程序调用云函数报错

A：1. 检查App.vue中云开发环境ID是否正确；2. 检查小程序AppID是否与云环境绑定；3. 检查云函数是否部署成功。

### Q5：批量部署很慢

A：72个云函数全部部署约10-20分钟，属正常。如部分失败，可单独重新部署。
