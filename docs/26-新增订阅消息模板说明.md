# 第二十六部分：新增订阅消息模板申请说明

**适用对象**：技术对接人
**前置条件**：sendSubscribeMessage云函数已改造（新增2个模板）

---

## 一、新增模板清单

本次开发新增2个订阅消息模板，已在`cloudfunctions/sendSubscribeMessage/index.js`的`TEMPLATES`对象中添加：

| 序号 | 变量名 | 模板ID占位符 | 用途 | 接收人 |
|------|--------|-------------|------|--------|
| 1 | dispatch_notice | tmpl_dispatch_notice | 书记批转通知 | 被批转的负责人 |
| 2 | overdue_escalation | tmpl_overdue_escalation | 超时升级通知 | 书记 |

---

## 二、模板1：书记批转通知

### 2.1 模板详情

| 项目 | 内容 |
|------|------|
| **模板名称** | 工单批转通知（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **接收人** | 被书记批转的责任人 |

### 2.2 关键词选择

| 关键词 | 类型 | 说明 |
|--------|------|------|
| thing1 | thing（事项） | 来信主题/工单类型 |
| thing2 | thing（事项） | 内容摘要 |
| time3 | time（时间） | 处理时限 |
| thing4 | thing（事项） | 书记批示 |

### 2.3 申请文案示例

```
本模板用于村支书将工单批转给责任人时，通知责任人及时处理。

使用场景：村民提交反映后，系统自动分配给对应责任人。对于需要书记亲自批转的工单，书记通过小程序将工单批转给指定责任人，批转后责任人需收到通知。

模板内容示例：
- 来信主题：环境卫生
- 内容摘要：村口垃圾堆积
- 处理时限：2026-01-10 17:00
- 书记批示：请重点处理
```

### 2.4 是否需要长期订阅

**否**（一次性订阅即可，书记批转时触发，但需责任人提前授权）。

---

## 三、模板2：超时升级通知

### 3.1 模板详情

| 项目 | 内容 |
|------|------|
| **模板名称** | 超时升级通知（或类似） |
| **所属类目** | 政务民生-社区服务 |
| **接收人** | 书记（所有管理员） |

### 3.2 关键词选择

| 关键词 | 类型 | 说明 |
|--------|------|------|
| thing1 | thing（事项） | 单标题 |
| thing2 | thing（事项） | 承办人（姓名+管什么） |
| number3 | number（数字） | 超时天数 |

### 3.3 申请文案示例

```
本模板用于工单超时3天以上时，自动通知村支书。由系统定时触发器（sendOverdueReminder云函数，每天8点执行）检测超时工单，超时3天以上的工单升级通知书记，书记需知晓并督办。

使用场景：村民提交工单后，责任人在3天内未处理，系统自动升级通知书记。书记收到通知后在考核看板督办。

模板内容示例：
- 工单标题：村口路灯损坏
- 承办人：李四（管道路水利）
- 超时天数：5
```

### 3.4 是否需要长期订阅

**是（建议申请长期订阅）**。因为由系统定时触发器自动发送，无法每次获取用户授权。需在微信公众平台申请长期订阅权限（政务民生类小程序可申请）。

---

## 四、配置说明

### 4.1 模板ID配置位置

**文件**：`cloudfunctions/sendSubscribeMessage/index.js`
**位置**：文件顶部的`TEMPLATES`对象

当前代码（占位符）：
```javascript
const TEMPLATES = {
  new_feedback: 'tmpl_feedback_notify',
  status_update: 'tmpl_status_update',
  new_task: 'tmpl_task_assign',
  price_update: 'tmpl_price_alert',
  overdue_reminder: 'tmpl_overdue_reminder',
  dispatch_notice: 'tmpl_dispatch_notice',         // 新增
  overdue_escalation: 'tmpl_overdue_escalation'      // 新增
}
```

**替换方法**：将`tmpl_dispatch_notice`和`tmpl_overdue_escalation`替换为微信公众平台申请的真实模板ID。

### 4.2 申请步骤

1. 登录 https://mp.weixin.qq.com
2. 「功能」→「订阅消息」→「公共模板库」
3. 搜索"工单"、"通知"等关键词
4. 选择最接近的模板
5. 选关键词（按2.2和3.2节）
6. 提交申请
7. 审核通过后获取模板ID
8. 替换代码中的占位符
9. 重新部署sendSubscribeMessage云函数

### 4.3 长期订阅申请

模板2（overdue_escalation）建议申请长期订阅：

1. 「功能」→「订阅消息」→「长期订阅模板」
2. 类目选「政务民生」
3. 提交村委会统一社会信用代码证书
4. 填写使用说明（如3.3节）
5. 审核约7-15个工作日

### 4.4 测试方法

1. 部署sendSubscribeMessage云函数
2. 云开发控制台→云函数→sendSubscribeMessage→测试
3. 输入测试参数：
```json
{
  "type": "dispatch_notice",
  "targetOpenid": "你的openid",
  "title": "环境卫生·一般",
  "content": "村口垃圾堆积",
  "deadline": "2026-01-10 17:00",
  "note": "请重点处理"
}
```
4. 检查微信是否收到订阅消息

### 4.5 常见问题

| 问题 | 解决方法 |
|------|---------|
| 模板ID错误（40037） | 检查TEMPLATES中的模板ID是否正确 |
| 用户未授权（43101） | 责任人需在小程序内授权订阅 |
| 参数格式错误（47003） | 检查关键词类型（thing/number/time）是否匹配 |
| 长期订阅申请被拒 | 补充使用场景说明，强调"政务民生+定时触发" |
