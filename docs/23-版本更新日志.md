## 23.1 版本号规范

### 23.1.1 命名规则

本平台采用**语义化版本号**（Semantic Versioning）：

**格式**：`主版本号.次版本号.修订号`（如 `2.0.0`）

| 版本号 | 变更场景 | 示例 |
|--------|---------|------|
| **主版本号**（X.0.0） | 重大架构调整、不兼容更新 | v1.0.0 → v2.0.0（新增32个云函数+17个页面） |
| **次版本号**（2.X.0） | 新增功能、向下兼容 | v2.0.0 → v2.1.0（新增家庭账号功能） |
| **修订号**（2.0.X） | Bug修复、小优化 | v2.0.0 → v2.0.1（修复订阅消息发送失败） |

### 23.1.2 版本号变更原则

| 变更类型 | 版本号变化 | 是否需重新审核 |
|---------|-----------|--------------|
| 架构调整 | 主版本号+1 | 是 |
| 新增功能 | 次版本号+1 | 是 |
| Bug修复 | 修订号+1 | 否（如不影响功能） |
| 文案修改 | 修订号+1 | 否 |

1. 代码zip包（命名：`village-bridge_vX.X.X_YYYYMMDD.zip`）
