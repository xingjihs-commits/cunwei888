# 37 - 培训计划

> 本文档面向村委会项目负责人，指导如何让村民、村委、管理员快速上手。

## 37.1 培训对象与目标

| 角色 | 培训目标 | 培训时长 |
|------|---------|---------|
| 普通村民 | 会反映、会查询、会签到 | 30 分钟 + 实操 |
| 责任人（村委委员） | 会查看派单、会处理回复 | 1 小时 + 实操 |
| 书记 | 会审核认证、会处理亲阅件、会回信、会广播 | 2 小时 + 实操 |
| 管理员 | 会用全部 admin 功能、会看运维监控 | 半天 |
| 技术运维 | 会部署云函数、会修代码、会故障定位 | 1 天 |

## 37.3 培训流程

### 37.3.1 部署前 1 周
1. 召开村两委会议，宣讲项目意义
2. 培训书记和管理员
3. 准备村民培训物料（海报/宣传单）

### 37.3.2 部署当天
1. 管理员开通账号
2. 录入班子成员、紧急电话、ICP 等配置
3. 内部测试核心链路（反映→派单→处理→评价→看板）

### 37.3.3 部署后 1 周内
1. 召开村民大会，演示小程序
2. 现场帮助 30+ 村民完成认证
3. 收集反馈，迭代优化

### 37.3.4 部署后 1 月内
1. 入户走访 20 户，了解使用情况
2. 根据反馈调整（字号/菜单/流程）
3. 形成稳定的村民使用习惯

## 37.4 培训考核

### 37.4.1 村民考核
- 能独立完成反映提交
- 能查询工单进度
- 能签到

### 37.4.2 责任人考核
- 能在 24h 内处理分配的工单
- 能上传处理照片
- 能更新进度百分比

### 37.4.3 书记考核
- 能审核认证
- 能处理亲阅件
- 能回信
- 能看懂考核看板

## 37.5 培训激励机制

- 完成 5 次有效反映的村民 → 公示墙表扬
- 月度考核前 3 名责任人 → 村委奖励
- 书记广播发布及时率高 → 上级表彰

## 37.6 二次培训

每季度组织 1 次复训：
1. 新功能介绍
2. 收集使用反馈
3. 解决遇到的问题
4. 巩固操作技能
