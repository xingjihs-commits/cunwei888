# 第十九部分：管理员账号开通指引

**适用对象**：村支书、村文书、技术对接人
**目的**：规范管理员账号开通、权限分配、换届交接

---

## 19.1 微信公众平台成员管理

### 19.1.1 登录小程序后台

1. 浏览器打开 https://mp.weixin.qq.com
2. 管理员微信扫码登录
3. 确认登录的是「村务连心桥」小程序

### 19.1.2 进入成员管理

1. 左侧菜单「管理」→「成员管理」
2. 点击「项目成员」标签
3. 显示当前所有成员

### 19.1.3 添加成员步骤

1. 点击「添加成员」按钮
2. 输入成员微信号（需对方确认）
3. 选择角色（运营者/开发者/数据分析者/体验成员）
4. 设置权限（可选）
5. 点击「确认添加」
6. 对方微信收到邀请，确认后生效

## 19.2 角色与权限说明

### 19.2.1 运营者

| 项目 | 说明 |
|------|------|
| 权限 | 能登录后台，发布内容、管理留言、查看数据 |
| 不能 | 上传代码、发布线上版本 |
| 适用场景 | 村文书、村委委员（信息发布员） |

### 19.2.2 开发者

| 项目 | 说明 |
|------|------|
| 权限 | 能上传代码、预览、提交审核 |
| 不能 | 发布线上版本、管理成员 |
| 适用场景 | 技术对接人 |

### 19.2.3 数据分析者

| 项目 | 说明 |
|------|------|
| 权限 | 仅能查看后台数据（访问分析、用户画像等） |
| 不能 | 发布内容、上传代码 |
| 适用场景 | 上级检查人员（仅查看不修改） |

### 19.2.4 体验成员

| 项目 | 说明 |
|------|------|
| 权限 | 无法登录后台，仅能扫码体验小程序 |
| 不能 | 登录后台、发布内容 |
| 适用场景 | 测试人员、上级领导体验 |

### 19.2.5 各角色适用场景与建议

| 角色 | 建议分配给 | 数量建议 |
|------|-----------|---------|
| 运营者 | 村文书+村委委员 | 2-3人 |
| 开发者 | 技术对接人 | 1人 |
| 数据分析者 | 上级街道办 | 按需 |
| 体验成员 | 测试人员 | 按需 |

## 19.3 针对村务场景的权限分配建议

### 19.3.1 权限分配表

| 岗位 | 微信公众平台角色 | 小程序内权限（admins集合role字段） | 主要职责 |
|------|-----------------|-------------------------------|---------|
| 村支书 | 管理员（最高权限） | role: 'super_admin' | 全部权限+书记信箱+广播+对上汇报 |
| 村主任 | 运营者 | role: 'admin' | 工单管理+内容发布+考核看板 |
| 村会计 | 运营者 | role: 'admin' | 财务三资发布+项目收益 |
| 网格员 | 运营者 | role: 'handler' | 工单处理+随手拍处理 |
| 村文书 | 运营者 | role: 'admin' | 信息发布+模块配置+数据备份 |
| 技术对接人 | 开发者 | role: 'tech' | 代码维护+云函数部署 |

### 19.3.2 权限分配步骤

1. 在微信公众平台添加成员（见19.1）
2. 在admins集合添加记录（见19.3.3）
3. 在小程序内根据role字段控制权限

### 19.3.3 admins集合添加记录

云开发控制台→数据库→admins集合→添加记录：

```json
{
  "_openid": "成员的openid",
  "name": "张三",
  "role": "super_admin",
  "enabled": true,
  "createTime": "2026-01-01"
}
```

**role字段可选值**：
- `super_admin`：超管（村支书）
- `admin`：管理员（村主任、村文书）
- `handler`：工单处理员（网格员）
- `tech`：技术（开发者）
- `reviewer`：内容审核员

## 19.4 功能权限精细化管理

### 19.4.1 配置每个成员能访问哪些后台页面

**当前实现**：所有管理员可访问全部管理端页面。

**建议增强**：在checkAdmin.js中增加权限校验：

```javascript
// 在checkAdmin.js中增加
module.exports.checkPermission = async function (openid, requiredRole) {
  const res = await db.collection('admins')
    .where({ _openid: openid, enabled: true })
    .limit(1)
    .get()
  
  if (res.data.length === 0) return false
  
  const role = res.data[0].role
  const roleLevel = {
    'super_admin': 5,
    'admin': 4,
    'reviewer': 3,
    'handler': 2,
    'tech': 1
  }
  
  return roleLevel[role] >= roleLevel[requiredRole]
}
```

### 19.4.2 限制成员只能发布"信息公示"

在publishNotice云函数中增加权限校验：

```javascript
// 在publishNotice中
const checkAdmin = require('../common/checkAdmin')
const canPublish = await checkAdmin.checkPermission(OPENID, 'admin')
if (!canPublish) {
  return { success: false, message: '无发布权限' }
}
```

### 19.4.3 限制成员不能查看"考核看板"

在getPerformanceDashboard云函数中增加权限校验：

```javascript
const canView = await checkAdmin.checkPermission(OPENID, 'super_admin')
if (!canView) {
  return { success: false, message: '无查看权限' }
}
```

## 19.5 账号安全

### 19.5.1 建议每位班子成员使用独立微信号

| 原因 | 说明 |
|------|------|
| 权限独立 | 每人独立权限，互不影响 |
| 操作留痕 | 操作日志记录openid，可追溯 |
| 安全性 | 一人一码，避免共用账号 |
| 离任处理 | 离任时只需移除本人openid |

### 19.5.2 操作日志留痕

所有管理操作写入logs集合：
```json
{
  "action": "操作类型",
  "operator": "操作人openid",
  "target": "操作对象",
  "createTime": "操作时间"
}
```

### 19.5.3 离任即移除权限

| 离任场景 | 处理步骤 | 时限 |
|---------|---------|------|
| 换届离任 | 1.移除admins记录；2.移除微信公众平台成员 | 离任当天 |
| 岗位调整 | 1.修改role字段；2.调整权限 | 调整当天 |
| 违规处理 | 1.移除admins记录；2.审查操作日志 | 立即 |

## 19.6 换届交接流程

### 19.6.1 旧管理员移除

1. 填写《管理员变更申请表》（见《04-数据备份与换届交接制度.md》第五节）
2. 村支书审批（如村支书本人离任，由上级街道办审批）
3. 云开发控制台→数据库→admins集合
4. 找到离任管理员记录
5. 将`enabled`改为`false`（软删除）或删除记录（硬删除）
6. 微信公众平台→成员管理→移除离任成员

### 19.6.2 新管理员添加

1. 获取新管理员openid（登录小程序后调用getUserInfo云函数）
2. admins集合添加记录（见19.3.3）
3. 微信公众平台→成员管理→添加成员
4. 培训新管理员（参见《09-村文书操作指南.md》）

### 19.6.3 权限重新分配

按19.3.1权限分配表，根据新班子岗位重新分配权限。

### 19.6.4 数据交接确认

填写《账号交接清单》（见《04-数据备份与换届交接制度.md》第四节），包括：
- 微信账号
- 云开发环境
- 数据库权限
- 管理员白名单
- 备份数据
- 全部文档

交接双方签字确认，上级街道办监督。

## 19.7 常见问题

### Q1：管理员忘记密码怎么办？

A：管理员无需密码，用微信扫码登录。如微信号丢失，联系微信公众平台客服（95173117）。

### Q2：管理员微信号被封怎么办？

A：1.在admins集合移除该openid；2.用新微信号重新添加；3.重新配置权限。

### Q3：如何查看谁操作过什么？

A：云开发控制台→数据库→logs集合，按createTime倒序查看，含operator字段可追溯操作人。

### Q4：管理员能删除村民反映吗？

A：管理员不能删除已公示工单（涉及治理留痕）。可驳回工单，需填写驳回原因，留痕记录。

### Q5：村支书不在村怎么办？

A：1.授权副职（role: 'super_admin'）代为处理；2.在admins集合添加副职openid；3.紧急情况由值班村支书处理。
